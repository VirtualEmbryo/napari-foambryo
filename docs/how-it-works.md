# How napari-foambryo works

napari-foambryo adds five docks to napari, under *Plugins › foambryo*, plus a reader, a writer and sample data. The plugin computes nothing scientific of its own: each dock calls a public function of delaunay-watershed (its packages dw3d for 3-D masks and dw2d for 2-D masks) or foambryo, the same function the `foambryo` command calls, with the same defaults. A result of the plugin is therefore the result of the command for the same mask and options.

The input decides the dimension. A Labels layer `(Z, Y, X)` is a 3-D mask; a layer `(Y, X)`, or a layer holding one plane `(1, Y, X)` (the leading axis is dropped, and the dock says so), is a 2-D mask; a `.rec` file is 2-D or 3-D by its own appendix or layout. Each dock follows the dimension of the layer or mesh chosen in it: its form, its defaults (resolved by the library for that dimension: `min_distance` 3 cubic voxels or 4 square pixels, the pressure method variational or laplace, the angle reading chord or arc) and the methods it offers.

## The docks

| dock | what it does | the library function it calls |
|---|---|---|
| **Reconstruct** | Takes a Labels layer and its voxel size, checks the mask, reports on it, estimates the time and memory, then builds the multimaterial mesh. *Pad thin medium margins*: delaunay-watershed's default (on for cubic voxels, off for a mask resampled to cubic voxels), on, or off; a choice other than the default is recorded in `run.json` and in the equivalent `foambryo mesh --pad-thin-medium-margins` / `--no-pad-thin-medium-margins`. | `foambryo.segmentation_masks.check_segmentation_mask` and `segmentation_mask_report` (the checks and the report); `foambryo.reconstruction_cost.estimate_reconstruction_cost` (the estimate); `foambryo.io.reconstruct_mask`, dw3d's default reconstruction, the one `foambryo mesh` runs (resampled to cubic voxels first when the voxels are longer along one axis) |
| **Infer** | Infers the tensions, then the pressures, of the reconstructed mesh or of a `.rec` file opened in napari; or a seed ensemble of the mask. | `foambryo.infer_tensions_then_pressures` (the two calls of `infer_forces`, as `foambryo infer`; `infer_tensions` alone when *pressures* is unticked); `foambryo.infer_tensions_over_seeds` for a seed ensemble, as `foambryo infer-over-seeds` |
| **Results** | Shows the tables of interfaces, cells and linear solves, the colour bars and the warnings; selecting a row shows its interface or cell. | the values Infer returned; the colours and ranges of `foambryo.colour_scales`, those of foambryo's Polyscope viewer |
| **View** | Explodes the cells apart, cuts the tissue with a plane normal to z, y or x, and sets the canvas's background. Nothing is computed again. | `DcelData.compute_scattered_arrays` (the displacement of the Polyscope viewer's scattered view); napari's clipping planes; `foambryo.colour_scales.BACKGROUND_COLOURS` |
| **Export** | Writes the files of the `foambryo` command into a folder, with the command lines that rebuild them. | the writers of `foambryo.results`; `foambryo.colour_scales.save_colour_bars` |

## The docks in 2D

| dock | what it does with a 2-D mask or mesh | the library function it calls |
|---|---|---|
| **Reconstruct** | Takes the pixel size `(y, x)` (from the layer, another layer or typed; square pixels only), checks and reports on the mask as in 3D, and builds the 2-D mesh. No time and memory estimate: a 2-D mask is meshed in about a second. `min_distance` is in square pixels, 4 by default. *Pad thin medium margins* as in 3D (on by default for square pixels). | `foambryo.io.reconstruct_mask`, which hands a 2-D mask to delaunay-watershed's 2-D reconstruction (dw2d), as `foambryo mesh` does; the same checks and report as in 3D |
| **Infer** | Young-Dupré tensions, each junction-graph component gauged alone, then Laplace pressures: the methods foambryo offers in 2D (the others are greyed out). No seed ensemble: dw2d has no random dither to vary. *Advanced › Angle reading*: the library's default for a 2-D mesh (`arc`, a circle fitted to each interface), or `chord` or `fitted_tangent`; a reading other than the default is recorded in `run.json` and in the equivalent `foambryo infer --angle-reading`. | `foambryo.infer_tensions_then_pressures` on the 2-D mesh, as `foambryo infer` |
| **Results** | The tables of interfaces and cells, the cells on the image border flagged (their pressures are reported, not withheld), the colour bars (the pressure scale runs over the cells) and the warnings. For the 2-D foam sample, the true tensions and pressures beside the inferred ones. | the values Infer returned; the colours and ranges of `foambryo.colour_scales` |
| **View** | Explode moves each cell away from the tissue's centre by its area centroid. There is no cut in 2D: the tissue is seen whole. Background as in 3D. | `foambryo.plotting_utilities.PlanarMeshDrawing.displacements`, the displacement foambryo's 2-D window uses |
| **Export** | The files of the `foambryo` command for a 2-D run, `run.json` recording `dimension = 2`, with the command lines that rebuild them. | the writers of `foambryo.results`; `foambryo.colour_scales.save_colour_bars` |

A 2-D mesh is drawn as 2-D Surface layers in the image's own frame `(row, column)`, over the Labels layer, as napari draws the labels: `<labels> interfaces` (the mesh before the inference, dark grey ribbons one pixel wide), `<labels> tensions` (each interface a ribbon in its tension's colour, an undetermined one green), `<labels> pressures` (each cell a filled polygon in its pressure's colour) and `<labels> image border` (grey, no value: the segments that close a cell cut by the image). The polygons are foambryo's own (`foambryo.plotting_utilities.planar_mesh_drawing`: each cell cut into triangles by ear clipping, exact for non-convex cells), the ones foambryo's Polyscope window draws.

**Which numbers to trust in 2D.** The pressures, from Laplace's law on the interfaces' curvatures, are measurements only for a tissue deformed by nothing but its own tensions and pressures. In an embryo inside its eggshell the cells are compressed against the shell, and an interface's curvature follows Laplace's law, and its tangent Young–Dupré, only close to the junctions: read the tensions only (untick *pressures*), with the `chord` reading (`fitted_tangent` as a check), not the arc reading. For a free tissue, which of the arc and the chord is closer to the truth on real masks is an open question. The plugin cannot tell a compressed tissue from a free one.

The reader opens a `.rec` or `.arec` mesh file (`foambryo.dcel_mesh_from_file`): a 3-D file as its cells and crop faces, a 2-D file as its interfaces and image border; a 2-D file written before delaunay-watershed 0.8.0, whose edges are stored the other way round, gives the same layers and numbers (foambryo measures a 2-D mesh's orientation). The writer saves a mesh layer as `.rec` (*File › Save Layer*). The sample data are, in 3D, benchmark case 000 (6 cells, with its true tensions) and three small generated foams (cubic voxels, voxels twice as long along z, and a foam cut by the image box); in 2D, a foam of 8 cells at mechanical equilibrium with its true tensions and pressures, and three frames of 4-cell *C. elegans* embryos (without eggshell, with eggshell, after hmr-1; hmp-2 RNAi), each its membrane image and its four cells, from the data of Yamamoto et al., Developmental Cell 61(6), 1273–1288.e4 (2026), doi:10.1016/j.devcel.2026.04.013, under CC BY-SA 4.0 (Zenodo doi:10.5281/zenodo.19627642; provenance in the package's `sample_data/README.md`). In the layer list, a Labels layer's right-click menu offers *Reconstruct with foambryo*, which opens Reconstruct on that layer.

## Where the work runs

A reconstruction, an inference and a seed ensemble each run in a separate process, so that napari stays responsive and **Cancel** stops the run at once and frees its memory. A cancelled or failed run adds nothing. The estimate shown before a run is foambryo's own, a fit to measured reconstructions, not a guarantee: when it exceeds the machine's memory, Reconstruct asks you to tick *run anyway*, or to run `foambryo mesh` on a larger machine and open the `.rec` file here.

## Where the results go

* **Into napari**, as layers: the mesh over the Labels layer, the tensions (one colour per interface), the pressures (one colour per cell), and, when they exist, the undetermined tensions (green outlines) and the crop faces (see-through glass); in 2D, the layers described above. Each layer is placed exactly on the voxels (or pixels) of its Labels layer.
* **Into the Results dock**: the tables, which *Export CSV* writes one at a time.
* **Into a folder, only when you click Export**: `mesh.rec`, `tensions.csv`, `pressures.csv`, `colour_bars.png` and `run.json` (with diagnostics, `solves.csv` and `spectra.npz`; for a seed ensemble, a `seed-ensemble/` folder; on request, `mask.npz`). They are the files the `foambryo` command writes for the same mask and options, and `run.json` lists the command lines that rebuild them. A folder that already holds such files is not changed without your confirmation, and no other file in it is ever touched.

Nothing else is written: the plugin keeps its runs in memory until napari is closed.

## What it leaves out

The plugin offers what the `foambryo` command offers, no more, and less in places: not the reconstruction seed (use a seed ensemble), the faces of the image box where the tissue really ends, the resampling method, the wedge refusal or the error bars of `foambryo.infer_tensions_with_uncertainty`. It draws no curvature and no stress, in 2D or 3D, and does not offer foambryo's opt-in global fit in 2D (`foambryo infer --tension-method equilibrium-tiling --mask MASK`). Use foambryo's command line, its viewer (`foambryo view`) or Python for those.
